# 재활치료부 통합 시스템 — 운영 안내 (한 장)

PC를 바꾸거나, 새 PC에 처음 설치하거나, 문제가 생겼을 때 이 문서만 보면 되도록 정리했습니다.

## 1. 새 PC에 설치하기
1. https://github.com/dop4773-ops/rehab-hub/releases/latest 에서 `rehab-hub-setup-버전.exe` 를 받아 실행합니다(설치 중 창이 잠깐 떴다 사라집니다).
2. 설치가 끝나면 바탕화면 아이콘으로 실행합니다. 업데이트는 앱이 알아서 확인합니다(설정 › 업데이트·정보에서 자동/수동 선택).
3. 환자 정보가 든 파일은 설치 파일에 들어 있지 않습니다. 아래 2번으로 폴더를 다시 연결하세요.

## 2. 옮기기: 설정과 폴더 연결
- **옛 PC**: 설정 › 관리·백업 › `설정 내보내기` → 파일 하나가 만들어집니다(폴더 목록 + 모든 설정 + 규칙 목록이 들어 있어요). USB나 메신저로 옮기세요.
- **새 PC**: 설정 › 관리·백업 › `설정 가져오기`로 그 파일을 고릅니다. 파일 안의 폴더 중 이 PC에 있는 폴더만 자동으로 연결됩니다. 없는 폴더는 설정 › 데이터·동기화에서 `+ 폴더 추가`로 다시 고르세요.
- 시간표·현황 파일이 있는 폴더(OneDrive 등)를 연결하면 `🔄 지금 업데이트`로 자동 인식됩니다. 필수 파일이 모두 보이는지 홈 위쪽 `필수 파일 6/6`로 확인합니다.

## 3. 이 PC에만 저장되는 것 (옮겨지지 않아요)
| 내용 | 위치/방법 |
|---|---|
| 그랜드라운딩 보관함 | 앱 데이터 폴더의 `schedules` 폴더 → 새 PC에 폴더째 복사 |
| 교차검증 제외 사유·확인함·이력, 홈 메모 | 앱 내부 저장소(`Local Storage`) → 앱 데이터 폴더 전체를 복사해야 옮겨짐 |
| 설정·규칙 | `설정 내보내기`에 포함(위 2번) |

앱 데이터 폴더 위치: 설정 › 업데이트·정보 › `데이터 저장 위치`에 경로가 보이고 `폴더 열기` 버튼으로 바로 열 수 있습니다(앱을 끈 뒤 복사하세요).

## 4. 문제가 생겼을 때
1. **앱이 흰 화면이 되거나 멈춤** → 자동으로 다시 불러옵니다. 계속되면 앱을 완전히 종료하고 다시 실행하세요.
2. **오류 기록**: 앱 데이터 폴더의 `error.log`(예상 못 한 오류 · 화면 자동 복구 기록, 200KB를 넘으면 처음부터 다시 씀). 문제를 알릴 때 이 파일의 맨 아래 몇 줄을 같이 주세요.
3. **업데이트가 안 됨** → 설정 › 업데이트·정보 › `기록 파일`(update-log.json)에서 확인·다운로드·설치 기록을 볼 수 있습니다. 인터넷이 막힌 PC는 위 1번 주소에서 새 설치 파일을 받아 덮어 설치해도 됩니다(데이터는 그대로 유지).
4. **파일이 안 읽힘** → 홈의 `필수 파일` 칩을 누르면 파일별 상태(최신/오래됨/없음)와 `📂 직접 고르기`, `↻ 이 파일만 다시 읽기`가 있습니다. 엑셀이 열려 있어도 읽기만 하므로 원본은 바뀌지 않습니다.
5. **인수인계가 오래된 값** → 홈/도구 위의 `인수인계` 칩(또는 Ctrl+Shift+H)으로 지금 다시 가져옵니다. 인터넷이 막히면 마지막으로 가져온 값을 쓰고, 오래되면 노랑/빨강으로 알려 줍니다.
6. **직원이 바뀌거나 오더 코드가 바뀜** → 설정 › 규칙에서 바로 고칠 수 있습니다(프로그램 새 배포 불필요).

## 5. 알아 두면 좋은 약속
- 앱은 원본 시간표·현황·인수인계 파일을 **읽기만** 하고 수정하지 않습니다(자동 검사로 지키고 있어요).
- 내보낸 엑셀·CSV는 기본으로 다운로드 폴더에 저장됩니다(설정 › 파일 저장에서 변경).
- 단축키 모음은 Alt 키를 두 번 누르면 나옵니다. Ctrl+K 환자 검색, Ctrl+Shift+H 인수인계 다시 가져오기, Ctrl+Shift+T 오늘 요약 복사.
