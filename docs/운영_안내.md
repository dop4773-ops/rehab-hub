# 재활치료부 통합 시스템 — 운영 안내 (한 장)

PC를 바꾸거나, 새 PC에 처음 설치하거나, 문제가 생겼을 때 이 문서만 보면 되도록 정리했습니다.

## 1. 새 PC에 설치하기
1. https://github.com/dop4773-ops/rehab-hub/releases/latest 에서 `rehab-hub-setup-버전.exe` 를 받아 실행합니다(설치 중 창이 잠깐 떴다 사라집니다).
2. 설치가 끝나면 바탕화면 아이콘으로 실행합니다. 업데이트는 앱이 알아서 확인합니다(설정 › 업데이트·정보에서 자동/수동 선택).
3. 환자 정보가 든 파일은 설치 파일에 들어 있지 않습니다. 아래 2번으로 폴더를 다시 연결하세요.

## 2. 옮기기: 설정과 폴더 연결
- **옛 PC**: 설정 › 관리·백업 › `설정 내보내기` → 파일 하나가 만들어집니다(폴더 목록 + 모든 설정 + 규칙 목록이 들어 있어요). USB나 메신저로 옮기세요.
- **새 PC**: 설정 › 관리·백업 › `설정 가져오기`로 그 파일을 고릅니다. 파일 안의 폴더 중 이 PC에 있는 폴더만 자동으로 연결됩니다. 없는 폴더는 설정 › 데이터·동기화에서 `+ 폴더 추가`로 다시 고르세요.
- 시간표·현황 파일이 있는 폴더(OneDrive 등)를 연결하면 `🔄 지금 업데이트`로 자동 인식됩니다. 필수 파일이 모두 보이는지 홈 위쪽 `필수 파일 6/6`로 확인합니다.

## 3. 이 PC에만 저장되는 것 (옮겨지지 않아요)
| 내용 | 위치/방법 |
|---|---|
| 그랜드라운딩 보관함 | 앱 데이터 폴더의 `schedules` 폴더 → 새 PC에 폴더째 복사 |
| 교차검증 제외 사유·확인함·이력, 홈 메모 | 앱 내부 저장소(`Local Storage`) → 앱 데이터 폴더 전체를 복사해야 옮겨짐 |
| 설정·규칙 | `설정 내보내기`에 포함(위 2번) |

앱 데이터 폴더 위치: 설정 › 업데이트·정보 › `데이터 저장 위치`에 경로가 보이고 `폴더 열기` 버튼으로 바로 열 수 있습니다(앱을 끈 뒤 복사하세요).

## 4. 문제가 생겼을 때
1. **앱이 흰 화면이 되거나 멈춤** → 자동으로 다시 불러옵니다. 계속되면 앱을 완전히 종료하고 다시 실행하세요.
2. **오류 기록**: 앱 데이터 폴더의 `error.log`(예상 못 한 오류 · 화면 자동 복구 기록, 200KB를 넘으면 처음부터 다시 씀). 문제를 알릴 때 이 파일의 맨 아래 몇 줄을 같이 주세요.
3. **업데이트가 안 됨** → 설정 › 업데이트·정보 › `기록 파일`(update-log.json)에서 확인·다운로드·설치 기록을 볼 수 있습니다. 인터넷이 막힌 PC는 위 1번 주소에서 새 설치 파일을 받아 덮어 설치해도 됩니다(데이터는 그대로 유지).
3-1. **OneDrive가 멈춘 것 같다는 안내** → 홈 위쪽 「OneDrive 꺼짐」(빨강)은 OneDrive 프로그램이 꺼져 있다는 뜻이니 작업 표시줄에서 켜세요. 「OneDrive 확인」(노랑)은 평일마다 고치는 파일이 이틀 넘게 안 바뀌었다는 뜻이라, 동기화가 멈췄을 수 있어요(아이콘 확인, 연휴면 무시). 설정 › 데이터·동기화에서 끌 수 있습니다.
3-2. **이 PC에서 안 될 때** → 설정 › 업데이트·정보 › 환경 점검 › 「점검 실행」. 폴더·파일을 읽을 수 있는지, OneDrive에서 아직 내려받지 않은 파일(「항상 이 장치에 유지」로 바꾸세요)이 있는지, 저장 폴더에 쓸 수 있는지 알려 줍니다. 「결과 복사」로 그대로 보내면 원인을 찾기 쉬워요.
3-3. **교차검증 위쪽의 「⚠ 자료가 평소와 달라요」** → 오늘 읽은 환자 수·카드 수 등이 최근 며칠과 크게 다르다는 뜻입니다. 파일이 일부만 올라왔거나(동기화 중), 엑셀 양식을 바꿨거나, 파일이 중복됐을 수 있어요. 데이터 준비에서 파일을 확인하고 「다시 검증」하세요. 정말 환자가 크게 늘고 준 것이면 무시해도 됩니다.
3-5. **파일을 덮어썼는데 반영이 안 돼요** → 기본 설정(설정 › 데이터·동기화 › 「바뀌면 바로」)에서는 저장이 끝난 뒤 약 10~40초 안에 자동 반영되고 알림이 떠요. 설정이 「앱 실행 시」·「수동」이면 「지금 업데이트」를 눌러야 합니다. 도구 화면에 직접 끌어다 놓은 파일은 추적되지 않아 다시 올려야 해요.
3-4. **아침에 한 번에 확인하고 싶을 때** → 홈의 「▶ 오늘 점검」(Ctrl+Shift+D). 파일·인수인계·교차검증·치료기록 QA를 차례로 돌리고 결과를 한 창에 모아 줍니다. 「결과 복사(카톡용)」으로 팀에 공유할 수 있어요.
4. **파일이 안 읽힘** → 홈의 `필수 파일` 칩을 누르면 파일별 상태(최신/오래됨/없음)와 `📂 직접 고르기`, `↻ 이 파일만 다시 읽기`가 있습니다. 엑셀이 열려 있어도 읽기만 하므로 원본은 바뀌지 않습니다.
5. **인수인계가 오래된 값** → 홈/도구 위의 `인수인계` 칩(또는 Ctrl+Shift+H)으로 지금 다시 가져옵니다. 인터넷이 막히면 마지막으로 가져온 값을 쓰고, 오래되면 노랑/빨강으로 알려 줍니다.
6. **직원이 바뀌거나 오더 코드가 바뀜** → 설정 › 관리·백업 › 고급에서 「규칙 편집 메뉴 보이기」를 켠 뒤 설정 › 규칙에서 고칩니다(잠금 해제 → 고치기 → 변경 내용 확인 → 저장, 프로그램 새 배포 불필요). 잘못 바꿨으면 「이전 값으로 되돌리기」나 「원래 규칙으로 전체 되돌리기」로 돌립니다.

## 4-1. 업데이트할 때 하던 작업은?
- 설정·검증 기록(제외/확인함)·수정 지시서 완료 표시·제외한 미액팅 칸·그랜드라운딩 메모/체크·보관함은 앱 데이터 폴더에 저장돼 있어 업데이트 뒤에도 그대로입니다.
- 업데이트로 다시 켜지면 하던 화면(검색·필터 포함)으로 돌아옵니다. 평소에 껐다 켜면 홈으로 시작합니다.
- **직접 끌어다 올린 파일**이나 **열려 있는 인수인계 수정 창**이 있으면 자동 업데이트는 설치를 미루고, 프로그램을 끌 때 설치됩니다(안내가 오른쪽 아래에 뜹니다). 폴더에 있는 파일은 다시 켜면 자동으로 다시 읽힙니다.

## 5. 알아 두면 좋은 약속
- 앱은 원본 시간표·현황·인수인계 파일을 **읽기만** 하고 수정하지 않습니다(자동 검사로 지키고 있어요).
- 내보낸 엑셀·CSV는 기본으로 다운로드 폴더에 저장됩니다(설정 › 파일 저장에서 변경).
- 처음 쓰는 사람을 위한 **도움말**이 앱 안에 있습니다(F1·상단 ❓·각 화면 위쪽 「❓ 사용법」은 지금 화면 설명만 작은 팝업으로, 사이드바 「도움말」은 전체 화면). 화면별 안내·용어 풀이·색 읽는 법·단축키·자주 묻는 문제가 들어 있고 검색할 수 있어요.
- 단축키 모음은 Alt 키를 두 번 누르면 나옵니다. Ctrl+K 환자 검색(Enter 동작·최근 기록은 설정 › 화면에서 선택, F2 = 검색창에 쓰기(설정 › 단축키에서 변경), Esc/닫기 버튼으로 닫기), Ctrl+Shift+H 인수인계 다시 가져오기, Ctrl+Shift+T 오늘 요약 복사.
