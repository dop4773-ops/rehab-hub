📦 데이터 준비

백업 상태를 확인하는 중…

🖨️ 보고서 / 출력

각 도구가 이미 분석해둔 내용을 이 화면에서 바로 내보낼 수 있습니다. 아직 한 번도 안 연 화면은 먼저 사이드바에서 열어 파일을 불러와야 합니다.

👤 그랜드라운딩

현재 대회진 RM으로 선택된 환자를 1개 시트 Excel로 내보냅니다(치료사별·언어치료 전용 등 다른 형식은 화면에서 직접 선택).

📋 치료기록 QA

지금까지 분석된 오류 목록을 CSV로 내보냅니다.

🔍 교차검증

현재 화면에 적용된 필터(탭) 기준 그대로 Excel로 내보냅니다.

⚙️ 폴더 연결 설정

시간표·현황 파일이 있는 폴더를 등록해 두면, "자동 불러오기"로 매번 자동 인식합니다. 여러 폴더를 등록할 수 있습니다.

🔄 데이터 자동 동기화

파일이 바뀌었는지는 30초마다 가볍게(파일 목록·수정시각만) 확인해 "업데이트 필요"로 표시합니다. 아래는 그 변경을 실제로 다시 읽어 반영하는 시점입니다. 바뀐 파일만 다시 읽습니다.

🖥 화면 기본값

데이터 준비 화면을 열 때 처음 보이는 모양입니다. 화면 위의 "목록형 / 보드형" 버튼으로 언제든 바꿔 볼 수 있고, "이 보기를 기본으로"로도 저장됩니다.
