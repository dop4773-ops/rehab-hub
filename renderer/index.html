파일이 바뀌었는지는 아래 "변경 감지 간격"마다 가볍게(파일 목록·수정시각만) 확인합니다. 이 설정은 바뀐 파일을 실제로 다시 읽어 반영하는 시점입니다. "수동"이면 "지금 업데이트"를 누를 때만 반영돼요.

📁 파일 저장

저장 위치
파일 저장 위치?-
그랜드라운딩·교차검증 등에서 엑셀·CSV를 내보내면 물어보지 않고 이 폴더에 바로 저장돼요. 같은 이름이 있으면 「이름 (1)」처럼 번호가 붙어서 덮어쓰지 않아요. 저장되면 오른쪽 아래에서 바로 열 수 있어요.
저장 후 안내
저장 안내 표시저장하면 오른쪽 아래에 「열기 / 폴더 보기」 안내를 띄웁니다
저장에 실패했을 때의 안내는 이 설정과 상관없이 항상 보여요. 안내는 「닫기」 버튼이나 Esc 키로 언제든 닫을 수 있어요.
안내가 저절로 닫히는 시간마우스를 올려 두면 닫히지 않아요
열기·폴더 보기를 누르면 안내 닫기끄면 파일을 연 뒤에도 안내가 남아 있어서 폴더도 이어서 열 수 있어요

🖥 화면

홈 화면
홈 화면 배치?작업대(한 화면 · 기능 가득) / 컴팩트 / 예전 카드형
작업대: 오늘 할 일(숫자 키로 실행) · 담당자별 확인 필요 · 다가오는 일정 · 오늘의 흐름 · 도구 타일(추세·바로가기) · 메모 · 오늘 요약 복사를 한 화면에 모았어요. 컴팩트: 할 일과 작은 타일만. 기존(카드형)은 예전 화면 그대로예요. 파일 현황은 위쪽 "필수 파일" 칩을 누르면 작은 창으로 열려요.
사이드바?왼쪽 메뉴의 시작 상태
"마지막 상태"는 직접 접고 펼친 것을 기억합니다. 펼침/접힘을 고르면 앱을 켤 때마다 그 상태로 시작해요.
보기
글자 크기화면 전체가 같은 비율로 커지거나 작아져요
색감?
"선명"은 같은 색의 채도를 높여 더 또렷하게 보여줍니다.
도구의 파일 업로드 영역?각 도구 위쪽 파일 칸의 시작 상태
"접힘"이어도 꼭 필요한 파일이 없거나 읽기 오류가 있으면 자동으로 펼쳐 줍니다.
데이터 준비 화면
기본 보기?화면 위 버튼으로 언제든 바꿔 볼 수 있어요
목록형은 필수/선택/실시간 묶음(신선도 막대·기능별 준비 상태), 층별 표는 3F·10F × 파일 종류 표, 보드형은 최신/확인 필요/선택 안 함 열로 보여줍니다. 데이터 준비 화면 위 버튼으로 언제든 바꿔 볼 수 있어요.
확인 필요 파일을 맨 위로?읽기 오류·업데이트 필요·없음 순서로 먼저 보여줍니다
목록형에서 각 묶음 안의 순서에 적용됩니다. 보드형은 열이 이미 상태별로 나뉘어 있어요.
선택 안 한 파일 숨기기못 찾은 선택 파일은 목록·보드에서 감춥니다
환자 빠른 검색 (Ctrl+K)
Enter를 누르면?검색창에서 환자를 고르고 Enter를 쳤을 때
전체시간표 크게: 그 환자의 시간표 카드를 큰 창으로 보여줘요. 검색 화면 그대로: 아무 데도 안 가고 검색창에서 계속 봐요. 화면 이동: 교차검증(이슈가 있으면) 또는 그랜드라운딩 화면으로 넘어가요. 검색창은 Esc 키나 「닫기」 버튼으로만 닫혀요.
최근 본 환자 저장끄면 검색창에 최근 본 환자를 남기지 않아요(검색창에서 바로 지우거나 끌 수도 있어요)

📐 규칙

직원이 바뀌거나 오더 코드가 달라질 때 프로그램을 새로 배포하지 않고 여기서 고칠 수 있어요. 처음 정해 둔 규칙이 기본값이고, 평소에는 잠겨 있어요. 바꾸려면 잠금을 풀고 → 고친 뒤 → 「변경 내용 확인」에서 바뀐 곳을 보고 저장해요. 저장하기 전에는 아무것도 적용되지 않고, 저장한 뒤에도 「이전 값으로 되돌리기」·「원래 규칙으로」·번호 칸 1·2·3으로 언제든 돌릴 수 있어요.

치료기록 QA · 오더 분류
작업치료(OT) 오더 코드이 코드로 시작하는 오더는 OT로 분류해요
언어·심리(ST) 오더 코드이 코드의 오더는 언어/심리로 분류해요
15분 고정 오더 코드이 코드의 오더는 치료 시간이 15분이어야 해요
치료기록 QA · 미액팅 시간표
ERDT에서 단독 "E"를 하는 치료사시간표 ERDT 구역에서 E 표시를 집계할 치료사 이름 (이 명단 밖에서 E가 나오면 경고하고 집계에서 빼요)
그랜드라운딩 · 회차별 병동
1회차 병동 (돌아가는 순서)예: 9, 8 → 10F에서 9병동, 8병동 순서
2회차 병동 (돌아가는 순서)예: 7, 5 → 7병동, 5병동 다음 3F
