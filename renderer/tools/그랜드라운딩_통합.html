3그랜드 라운딩 확인 및 Excel 추출

작업·연하·인지 치료사 매칭 미업로드 · 작업치료현황의 평일시간표(원본)에서 작업(ST/SM 등)·연하(R)·인지(CCRT/BETTER/COMCOG) 치료사를 분리 매칭합니다. 불러오는 중 · OT인수인계서(통합)에서 실시간으로 Goal / 그랜드라운딩을 가져옵니다. 환자명+주치의 기준으로 치료별로 매칭합니다.
물리치료사 매칭 10F 미업로드 3F 미업로드
치료사별·팀별 분류 작업치료현황을 업로드하면 치료사별로 나눠 Excel을 만들 수 있습니다. "팀" 시트가 있으면 위에서 팀을 선택해 그 팀만 뽑을 수 있습니다.
진료부/병동용 보기는 치료사 매칭 열을 숨기고, 회차 동선·환자 위치·시간표·Goal·인수인계 그랜드라운딩·회진 발표 요약 중심으로 표시하고 출력합니다. 재활치료부 탭에서 업로드한 인수인계 내용은 그대로 반영됩니다. Excel은 선택 RM의 환자를 1개 시트로 출력하며, 진료부/병동은 A4 세로 1장에 맞추며, `전체` 시간대 출력은 재활치료부에서만 사용합니다. 특정 병동 선택 시 오전 출력의 11:25 오른쪽(오후는 마지막 시간 오른쪽)에 특이사항 빈칸이 추가됩니다.
실제 운영 회차를 그대로 적용합니다. 1회차는 8·9병동 담당 환자를 대상으로 10F 재활치료실 → 9병동 → 8병동 순서로 이동합니다. 2회차는 5·7병동 담당 환자를 대상으로 10F 재활치료실 → 7병동 → 5병동 → 3F 재활치료실 순서로 이동하며 702~705호 환자도 포함합니다. 09시 회진이면 09:05 시점에 10F에서 치료 중인 환자를 먼저 배치하고, 해당 시점에 치료가 없는 환자는 병실로 배치한 뒤 병동과 3F 순서로 이어집니다. 화면에서는 하루 전체 시간표를 유지하고, Excel은 오전·오후·전체 중 선택한 시간대를 출력하며, 재활치료부에서 전체를 선택하면 08:30~16:30의 모든 치료시간을 한 번에 출력합니다. 병동 필터를 선택하면 해당 병동 환자만 동일한 회진 동선 기준으로 화면과 Excel에 반영됩니다.

Grand Rounding Route

시간표를 업로드하면 1회차/2회차 실제 동선에 맞춰 대상 환자를 자동 배치하고, 각 구간 안에서 회진 시간대 순으로 정렬합니다.

치료실 도면 · 그랜드 라운딩 동선 참고 보내주신 실제 도면을 기준으로 출입구에서 가까운 순서대로 10층·3층 치료위치 우선순위를 세분화했습니다. T-번호는 작업치료 테이블로 인식하며, 그랜드 라운딩 Excel에는 마지막에 치료실 도면 시트를 1개 추가해 두 사진을 함께 넣습니다.
대회진용 기준: 환자 행의 1순위는 실제 회차 동선입니다. 1회차는 10F → 9병동 → 8병동, 2회차는 10F → 7병동 → 5병동 → 3F를 절대 순서로 사용합니다. 회진 시작 시점의 첫 치료타임을 기준으로 10F 치료환자를 먼저 배치하고, 치료가 없는 환자는 병실로 배치한 뒤 각 병동과 3F 순서로 정렬합니다. 작업치료현황을 업로드하면 상단 시간표의 ST/SM 등은 작업치료사, R은 연하치료사로 분리하고, 하단 10F CCRT 및 3F BETTER·COMCOG 배정은 인지치료사로 선택 요일에 맞춰 매칭합니다. 10F·3F 물리치료시간표를 추가 업로드하면 물리치료사도 함께 표시합니다. OT 인수인계서를 업로드하면 선택한 주치의와 환자명을 기준으로 환자의 모든 치료행을 모아 치료종류·치료사별 Goal·그랜드라운딩을 같은 행끼리 한 쌍으로 표시합니다. 그 옆의 회진 발표 요약은 모든 Goal·그랜드라운딩에서 가장 중요한 목표 1~2개와 핵심 치료방향 1~2개만 추려 정리하고, 꼭 보고할 특이사항이 있을 때만 한 문장을 추가해 짧은 1~2문장으로 자동 정리하며 직접 수정할 수 있습니다. 현재 환자에 없는 인수인계 대상(퇴원 가능)과 인수인계 미작성 환자도 미리 알려줍니다. 작업·연하 치료사는 평일시간표(원본) 상단 메인표에서 읽고, 인지치료사는 하단 10F CCRT 및 3F BETTER·COMCOG(3F 인지치료 배정) 구역만 선택 요일 기준으로 읽습니다. ERDT·퇴원예정자·환자특이사항 구역은 치료사 매칭에 사용하지 않습니다. 업로드된 실의 치료사 열만 자동으로 생성됩니다. 10F는 실제 도면 기준으로 A/B/D 구역 → 전동자전거·기립대·워커메이트 → 전기 → 트레드밀 → C구역 → T 작업치료 테이블 → 연하/언어/인지/도수실 순, 3F는 가구역 → 나구역 → 전기 → T 작업치료 테이블 → 트레드밀/기구치료실 → 통증/도수/ADL → 연하/인지/언어/임상심리실 순으로 정렬합니다. 회진 시간대에 치료가 없으면 병실 / 병실번호로 표시하고, 오른쪽 환자 시간표는 08:30부터 하루 전체 스케줄을 유지합니다. Excel 출력은 오전(08:30~11:25)·오후(13:00~16:30)·전체(08:30~16:30)를 선택할 수 있으며, 전체는 재활치료부에서 오전·오후 모든 치료시간을 한 번에 출력합니다. 재활치료부와 진료부/병동 모두 RM별 환자표 1개 시트로 출력하고, 마지막에 치료실 도면 공통 시트 1개를 추가합니다. 재활치료부와 진료부/병동 모두 A4 세로 1페이지에 맞춥니다. 진료부/병동에서 특정 병동을 선택하면 시간표 오른쪽에 병동 수기용 특이사항 열을 추가합니다.
시간표를 업로드하면 대회진 전용 동선 화면이 표시됩니다.
※ 동일 환자가 원본의 A/X/AU 등 여러 카드에 남아 있으면 등록번호+이름 기준으로 묶고 작성일이 가장 최근인 카드를 사용합니다. Excel 상단은 오전 치료시간 / 점심시간 / 오후 치료시간으로 구획하고, 환자 기본정보 헤더도 항목별 색으로 구분합니다. 치료시간은 치료명(치료층), 치료구역 형식이며 치료 종류별 배경색을 유지합니다. RM 회진표의 전체 병동 출력은 10F↔3F 전환 지점을 굵은 테두리로 구분하고, 특정 병동 출력은 호실순으로만 정렬하며 굵은 구분선을 넣지 않습니다. A4 세로 1페이지에 맞춥니다. Excel 추출은 화면의 환자 구분·병동·치료 층·검색 필터를 그대로 반영합니다. 그랜드 라운딩은 실제 회차별 대상 병동을 적용합니다. 1회차: 8·9병동 / 10F → 9병동 → 8병동, 2회차: 5·7병동 / 10F → 7병동 → 5병동 → 3F 순서를 최우선으로 고정합니다. 회진 시작 시각의 첫 치료타임(예: 09시=09:05)을 회진 위치 판단에 사용하고, 10F 치료환자 → 병동 환자 → 3F 치료환자 순으로 정렬합니다. 08:30은 전체 환자 시간표의 이전 타임으로 계속 표시합니다. 화면의 오른쪽 시간표는 08:30부터 전체 시간대를 표시하고, 재활치료부 Excel은 오전·오후·전체 중 선택한 시간대를 출력합니다. 점심시간은 시간 헤더에만 표시합니다.
